# НовыйГодЧат — V10 complete patch

Патч накладывается поверх актуального проекта V8/V9 без копирования MP3, котов и других тяжёлых ассетов.

Исправлено после проверки V9:
- CSS теперь заменяет именно `css/styles.css` (раньше V9 ошибочно содержала корневой `styles.css`, который не подключался);
- «Живая ёлка» открывает модалку и сразу загружает состояние;
- звезда добавляется из открытой ёлки и ограничивается одной звездой на пользователя в день;
- восстановлена полноценная «Стена славы» и её скрипт;
- фейерверк использует корректный DPR на мобильных;
- финальные 10 секунд запускаются перед глобальным новогодним фейерверком;
- секретные команды больше не отправляются как обычные сообщения;
- эффекты фона отправлены за интерфейс и не должны перекрывать карточки;
- закрытие модалок корректно снимает блокировку прокрутки.

После наложения патча на проект выполнить обновлённый `init-db.sql` для таблиц V9.
